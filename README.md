# Bora DF

Uma agenda visual de rolês em Brasília. A página reúne eventos de música, comida, arte e atividades ao ar livre, com busca, filtros por categoria e favoritos salvos no navegador.

[Acessar o site publicado — Bora DF](https://gersonjunior-afk.github.io/ponte404/)

## Como abrir

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências nem iniciar um servidor.

## Funcionalidades

- Busca por nome, local ou categoria do evento.
- Filtros por categoria.
- Favoritos persistidos no armazenamento local do navegador.
- Atalho `/` para focar a busca e `Esc` para sair dela.
- Layout adaptado para celular e desktop.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: estilos e layout responsivo.
- `js/script.js`: dados dos eventos, filtros, busca e favoritos.

## Imagens e fontes

As imagens dos eventos e as fontes tipográficas são carregadas de serviços externos. É necessária uma conexão com a internet para exibi-las; a página e suas interações continuam locais.
